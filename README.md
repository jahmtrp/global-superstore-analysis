# Global Superstore: Supply Chain & Delivery Analysis

## Project Overview
This project analyzes the logistics performance of a global superstore to identify cost-saving opportunities and improve delivery efficiency. The dataset was preprocessed and visualized to uncover trends in shipping costs and delivery status.

## Tools Used
* **Data Preprocessing:** R (Handled data cleaning, transformation, and calculated delivery durations)
* **Data Visualization:** Power BI (Built an interactive dashboard to track KPIs and logistics trends)

## Key Insights
* **Delivery Performance:** Nearly 40% of total shipments experienced delays, highlighting a critical area for supply chain improvement.
* **Seasonal Cost Spikes:** Trend analysis reveals that shipping costs consistently peak during the 4th quarter (Q4) of every year.
* **Cost by Shipping Mode:** While 'Standard Class' is the most utilized shipping method, it also accounts for the vast majority of the total shipping expenses.

## Repository Contents
* `data_cleaning.R`: R script used for data preparation and cleansing.
* `clean_global_superstore.csv`: The processed dataset ready for visualization.
* `global-superstore-dashboard.pbix`: The interactive Power BI dashboard file.
